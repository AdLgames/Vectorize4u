# Licensing decisions

Every third-party component the product ships or invokes, and the decision
recorded at the time. §2 of the spec requires this file to exist before
coding; it is kept current, not reconstructed later.

## Tracers

| Component | Licence | How we use it | Decision |
|---|---|---|---|
| `vtracer` | MIT | Invoked as a CLI subprocess | Safe to ship and to link if we ever wanted to. We still use the binary, for sandboxing and crash isolation (§3.5). |
| `potrace` | **GPLv2** | Invoked as a CLI subprocess only | **Never linked.** The engine shells out to `/usr/bin/potrace` and communicates over files. Mere aggregation / separate-process invocation does not make our code a derivative work. If this is ever judged unacceptable, ship colour-only via vtracer: `ENGINE_POTRACE_BIN` unset makes every potrace candidate drop out and `LINE_ART`/`SKETCH` fall back to vtracer presets. |

Any change that links potrace, or bundles it into a single distributed
binary with our code, needs legal review first.

## EPS toolchain — decided

**We write EPS ourselves** (`engine/emit.py: to_eps`). Filled polygons are
all the format needs for our output, and a hand-written writer is a few
dozen lines.

The alternative was Ghostscript, which is **AGPL** and would impose network
copyleft on a SaaS. §2 requires an explicit decision before pulling it in:
the decision is no. If EPS ever needs features beyond filled paths,
re-open this rather than quietly adding a `gs` call.

## Corpus and comparison material

- `benchmarks/corpus/` ships **synthetic** fixtures generated by
  `benchmarks/fixtures.py`. No third-party image rights are involved.
- Real corpus images (`benchmarks/corpus/real/`) must be public-domain/CC0
  or owned by us. Record the source of each in `real/labels.json`.
- Competitor output used in `make ab-external` is obtained through a normal
  paid account, kept out of the repository, and used for **internal
  comparison only**. Check the competitor's terms before each round.

## Centerline tracing (evaluated, Phase 8)

§0 records autotrace's GPL as the reason single-line tracing was deferred.
For the record, that reason does not stand on its own: autotrace could be
invoked the same way potrace is — a separate binary, a subprocess, never
linked, no GPL obligation on this code — and the arrangement is already
documented above.

It is moot in practice. `engine/centerline.py` produces centerlines from
scikit-image's `skeletonize` (BSD-3-Clause, already a dependency) and the
curve fitter in `engine/geom.py`, so no new licence enters the picture at
all. What stopped it being adopted is engineering cost, not licensing —
see docs/architecture.md.
